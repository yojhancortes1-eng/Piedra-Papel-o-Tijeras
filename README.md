Piedra, Papel o Tijeras

Descripción del proyecto
Este proyecto consiste en desarrollar un juego interactivo de Piedra, Papel o Tijeras, en el que el usuario podrá competir contra la computadora seleccionando una de las tres opciones disponibles.

Objetivo general
Desarrollar un juego digital sencillo, interactivo y fácil de utilizar, aplicando conceptos básicos de programación y herramientas de gestión de proyectos mediante GitHub.

Objetivos específicos
- Crear una interfaz sencilla y agradable para el usuario.
- Implementar las reglas tradicionales del juego.
- Permitir que el usuario seleccione piedra, papel o tijeras.
- Generar una elección aleatoria por parte de la computadora.
- Mostrar los resultados de cada ronda.
- Registrar los avances y mejoras del proyecto en GitHub.

Reglas del juego
- Piedra vence a tijeras.
- Tijeras vence a papel.
- Papel vence a piedra.
- Si ambos jugadores eligen la misma opción, se produce un empate.

Tecnologías
- HTML
- CSS
- JavaScript
- GitHub

Gestión del proyecto
El desarrollo se organizará mediante repositorios, Issues, commits, ramas y GitHub Projects, con el propósito de documentar y controlar los avances del producto digital.
